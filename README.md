# Join: Kanban Task Management App

Join is a Kanban-based task management application that lets teams organize, assign, and track their work through an intuitive drag-and-drop board. It was built as a collaborative team project during the Fullstack/AI Software Developer program at **Developer Akademie**.

## About the Project

The goal of Join was to build a fully functional, production-style task management tool from scratch, covering everything from user authentication and contact management to a real-time, database-backed Kanban board. The project focuses on clean component architecture, state management, and collaborative Git workflow within a team.

## Features

- 🔐 **Authentication:** user sign-up and login
- 🗂️ **Drag & Drop Board:** move tasks freely between status columns
- ✏️ **Task Management:** create, edit, and delete tasks with details like priority and due date
- 👥 **Task Assignment:** assign tasks to specific team members
- 📇 **Contact Management:** add, edit, and remove contacts
- ☁️ **Realtime Database:** all data is synced and persisted via Supabase

## Getting Started

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 22.1.4.

**Install dependencies**
```bash
npm install
```

**Start the development server**
```bash
ng serve
```
Open your browser at `http://localhost:4200/`. The app reloads automatically when you edit any source file.

**Build for production**
```bash
ng build
```
Build artifacts are stored in the `dist/` directory.

**Run unit tests**
```bash
ng test
```
